# skills.sh 分类归档目录（在线可部署）

可搜索、可分类筛选的 [skills.sh](https://www.skills.sh/) Agent Skills 归档站。  
静态站点，配置了 GitHub Pages / Vercel / Netlify 部署文件。

GitHub Actions 的 **Build & Deploy** 定时任务已关闭：仓库里没有 `scripts/build_catalog.py`，每日 cron 会一直失败并发送邮件。

## 仓库

https://github.com/rorywang98-netizen/skills-sh-catalog

## 内容

- 官方 8 Topics（skills.sh 精选）
- 生态归档 12 类（Azure / 飞书 / 媒体等）
- 热门榜 Top200

安装 skill：`npx skills add <owner/repo> --skill <name>`
